# Data

The image corpus is not redistributed in this repository. The analysis in
`./reproduce.sh` (default mode) does not need it: it works from the saved run
records in `results/`. The images are needed only for `./reproduce.sh full`.

## Real seed images

| corpus | classes | images | source |
|---|---|---|---|
| Soybean seeds | Broken 1,002; Immature 1,125; Intact 1,201; Skin-damaged 1,127; Spotted 1,058 | 5,513 | Mendeley Data, https://doi.org/10.17632/v6vzvfszj6.6 (Kaggle mirror `warcoder/soyabean-seeds`) |

It is a folder of single-seed RGB photographs, one subfolder per class.

```bash
pip install kaggle                  # needs an API token in ~/.kaggle/kaggle.json
bash data/download.sh               # soybean -> data/soybean_seeds
python scripts/count_corpus.py data/soybean_seeds   # check per-class counts
```

The pipeline splits the corpus once (stratified; 20% test, 10% validation,
seed 42), keeps the validation and test sets real-only, and imposes scarcity only
on the training split by keeping n in {25, 50, 100, 200} images for each minority
class. `results/soybean/provenance.json` records the file count and an inventory
digest of the corpus used for the reported run.

## Synthetic seed images

Synthetic images are generated by the pipeline, not downloaded
(`python -m diffseed.run --stage generate`). Each generator is trained only on
the scarce training split and produces 400 images per minority class:

| arm | model |
|---|---|
| `ddpm_fixed` | class-conditional pixel DDPM from scratch, 128x128, 8,500 steps, condition dropout 0.10, classifier-free guidance 2, 500 ancestral sampling steps, EMA weights |
| `ddpm_v1` | earlier DDPM whose class conditioning does not reach the denoiser (kept as a negative control) |
| `ddpm_ft` | pretrained pixel DDPM (`google/ddpm-celebahq-256`) fine-tuned at 128x128 |
| `sd_lora` | Stable Diffusion 1.5 with a rank-16 LoRA, 512x512, 3,000 steps |
| `sd_lora_sdedit` | the same LoRA used image-to-image (SDEdit) from real training seeds |
| `sd_turbo_lora` | LoRA on SD-Turbo |
| `dcgan`, `fastgan` | GAN baselines (FastGAN with DiffAugment) |

The generated image sets and trained generator/classifier weights from the
reported runs (about 5 GB) are not included; they are available from the
authors on request.
